# Ejemplos

| Archivo | Para qué sirve |
| :--- | :--- |
| `axon.toml` | Configuración de ejemplo con todas las claves y sus valores por defecto |
| `demo_axon.ps1` | Muestra colores, estilos y Nerd Font en la terminal |
| `demo_herdr_tui.ps1` | Demo de una TUI con ratón (SGR 1006) y pantalla alterna |
| `show_image.py` | Imagen inline con el protocolo iTerm2 (OSC 1337); requiere Python y Pillow |
